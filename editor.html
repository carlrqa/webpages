InlineVideo Flow Editor
How to use this editor
  1. 1 · Build On the left, set your options and add steps. For each Video step choose a Video source — paste a hosted link (YouTube/Vimeo/MP4) or pick a local file to upload alongside the page. Add branching choices to send viewers to other steps or webpages. The right shows a live preview.
  2. 2 · Publish Click Download standalone page — this is your video page (one HTML file). Upload it (plus any local video files) to your host (e.g. Netlify). It now has a web address like https://your-site.netlify.app/video.html. Put that address in the Hosted page URL field.
  3. 3 · Embed Click Copy embed snippet (bottom-right) and paste that one line into a Text/HTML block on your CMS page. Done.
